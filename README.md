# Модель опустынивания v1.10.0

Python-прототип пространственно-временной модели с GUI. Базовый сценарий —
«Случайные очаги», другие условия эксперимента задаются вручную.

В локальном архиве `charts/` хранятся материалы НИР, включая численную
сходимость, зависимость от осадков, сравнение засух с одинаковым дефицитом
и готовые изображения для презентации. Для запуска модели и тестов
достаточно файлов репозитория.

## Математическая модель

```math
V_t=D_V\nabla^2V+
rG(x,y)V(1-V)\frac{W}{W+K_W}\frac{S}{S+K_S}
-mV\frac{K_d}{W+K_d},
```

```math
W_t=D_W\nabla^2W+P(x,y,t)-eW-cVW,
```

```math
S_t=r_sQ(x,y)V(1-S)-d_s(1-V)\frac{K_d}{W+K_d}S.
```

Здесь $G$ — местный множитель роста растительности, $Q$ — восстановления
почвы. Они положительны, фиксированы во времени и в среднем равны 1.
В неподвижном режиме $P(x,y,t)=P(t)R(x,y)$, где $R$ — прежний постоянный
множитель осадков. В движущемся режиме к нему добавляется переносимый
погодный рисунок с нормировкой среднего. Средние местные осадки в обоих
режимах остаются равными $P(t)$. Это непрерывный модельный приток воды;
частота отдельных дождевых событий отдельно не калибровалась.

$V$ и $S$ ограничены от 0 до 1, $W \ge 0$ без верхнего ограничения.
Множитель засухи $`K_d/(W+K_d)`$ положителен и ослабевает при росте $W$.
Время **безразмерное**: шаг 0.05 не означает день, месяц или год.

Индекс опустынивания:

```math
D(x,y,t)=0.4(1-V)+0.3\bigl(1-\min(W,1)\bigr)+0.3(1-S),
\qquad D_{mean}(t)=\operatorname{mean}(D).
```

$D$ находится в $[0,1]$ и служит результатом расчёта $V$, $W$, $S$;
он не управляет их эволюцией. Основной график показывает средний $D$
одной линией, без полосы и подписи процентилей. Пороговой классификации
нет. Реакция модели может быть нелинейной; графики не сглаживаются
искусственно.

Отдельная **карта распространения пустыни** использует плавное
распределение по местному индексу.

```math
z=\operatorname{clip}\!\left(\frac{D-0.40}{0.50},0,1\right),
\qquad \mu=z^2(3-2z).
```

Цвет плавно переходит от зелёного ($\mu=0$) к песчаному ($\mu=1$),
сохраняя промежуточные значения. Переход растянут по диапазону
$`0.40\le D\le 0.90`$. Это способ изображения степени распространения,
без классификации клеток в 0/1, округления площади или случайного
перераспределения клеток. Карта зависит от локальных V, W, S,
а её отображение не меняет уравнения модели.

## Неявная конечно-разностная схема

Сетка:

```math
x_i=i\Delta x,\qquad y_j=j\Delta y.
```

Пятиточечный лапласиан:

```math
\nabla^2u_{ij}\approx
\frac{
u_{i+1,j}+u_{i-1,j}+u_{i,j+1}+u_{i,j-1}-4u_{ij}
}{h^2}.
```

На границе используется условие Неймана:

```math
\frac{\partial u}{\partial n}=0.
```

По времени используется неявная схема с итерациями Пикара.

Обозначим

```math
R_V(V,W,S)=
rG(x,y)V(1-V)\frac{W}{W+K_W}\frac{S}{S+K_S}
-mV\frac{K_d}{W+K_d},
```

```math
R_W(V,W,t)=P(x,y,t)-eW-cVW,
```

```math
R_S(V,W,S)=
r_sQ(x,y)V(1-S)-d_s(1-V)\frac{K_d}{W+K_d}S.
```

На шаге $`n\to n+1`$ начинаем с

```math
V^{(0)}=V^n,\quad
W^{(0)}=W^n,\quad
S^{(0)}=S^n.
```

Затем повторяем:

```math
(I-\Delta tD_VL)V^{(k+1)}
=
V^n+\Delta tR_V(V^{(k)},W^{(k)},S^{(k)}),
```

```math
(I-\Delta tD_WL)W^{(k+1)}
=
W^n+\Delta tR_W(V^{(k)},W^{(k)}),
```

```math
S^{(k+1)}
=
S^n+\Delta tR_S(V^{(k)},W^{(k)},S^{(k)}).
```

Остановка:

```math
\max(
\|V^{(k+1)}-V^{(k)}\|_\infty,
\|W^{(k+1)}-W^{(k)}\|_\infty,
\|S^{(k+1)}-S^{(k)}\|_\infty
)<\varepsilon.
```

Диффузионные матрицы разреженные. Их LU-разложение вычисляется один раз и затем переиспользуется на каждом шаге времени.

Это не полностью нелинейная неявная схема: диффузия неявная, а нелинейная реакционная часть линеаризована итерациями Пикара. Это хороший компромисс для первого рабочего прототипа.

## Запуск

Для запуска нужен Python с Tkinter. Команды ниже рассчитаны на
PowerShell в Windows.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Если окружение уже создано, достаточно последней команды.
В заголовке окна должна быть версия **v1.10.0**.

## Интерфейс

- **Восстановить базовые параметры** возвращает сценарий «Случайные
  очаги» и начинает расчёт заново, сохраняя текущие seed и число очагов.
- **Новые случайные очаги (1–8)** меняет seed, число и размещение
  очагов вместе с картами местных условий. **Сброс / применить**
  повторяет тот же набор при прежних seed и параметрах.
- **Режим начальных очагов**: центральный очаг, случайное число 1–8
  или заданное число со случайными центрами (от 1 до 20).
  Потери в перекрывающихся очагах берутся как максимум, не суммируются.
- **Постоянные различия территории**: разброс осадков, роста V и
  восстановления S. Допустимы значения от 0 до 0.95; ноль отключает
  соответствующий постоянный эффект. После изменений нажмите
  **Сброс / применить**.
- **Фон V ±, W ±, S ±** управляет исходными отклонениями;
  **Масштаб фона** — длиной гладких участков в координатах области.
  Тот же масштаб используется для постоянных местных условий.
- **Режим осадков**: постоянные, линейное уменьшение до Pmin,
  линейное увеличение до Pmax или сезонный синус с периодом Tseason.
  Отрицательные сезонные осадки заменяются нулём. График показывает
  среднее P(t) и диапазон местных значений.
- **Рассчитать заданное число шагов** продолжает текущий расчёт в
  фоновом потоке; остановка происходит после текущего шага.
- Карты **V, W, S, D** показывают рассчитанные поля. Шкалы V, S, D
  фиксированы на [0,1]. Для W по умолчанию используется диапазон
  текущего поля, чтобы небольшие абсолютные значения не скрывали
  пространственные различия. Минимум и максимум W указаны на карте.
  Геометрия карт сохраняет отношение сторон области.
- **Шкала влажности** переключается без сброса модели: «Текущий
  диапазон» показывает местные различия, «Общая: от 0 до ≥1»
  использует прежнюю шкалу от нуля, расширяемую при $W>1$. В текущем
  диапазоне цвет между разными моментами времени сравнивайте
  по числам на легенде. Сами W и уравнения не меняются. Для почти
  однородного поля ширина шкалы ограничена снизу значением
  $`\max(0.02, 0.05\max(W))`$, чтобы не усиливать численный шум.
- **Карта осадков** выбирает неподвижное распределение или движущиеся
  дождевые области. Режим применяется после сброса.
- **Осадки на территории** показывает фактическое P(x,y,t) в текущий
  момент. В движущемся режиме рисунок меняется во времени. При $P(t)=0$
  вся карта равна нулю. Подпись сообщает средние осадки P(t).
- **Распространение пустыни**: плавная карта местной степени распространения.
- **Динамика индекса**: средний D без полосы процентилей.
  **Динамика V, W, S**: средние состояния территории.
  **Осадки P(t)**: средний приток воды и пространственный диапазон.

## Постоянная пространственная неоднородность

Базовый сценарий: $P_0=0.03$, область 10×10, сетка 80×80, шаг 0.05.
Случайно выбираются число очагов от 1 до 8 и seed. Базовая ширина
очага 0.65 с разбросом 0.30; начальные падения V, W, S равны 0.30
с разбросом силы 0.30. Гладкие начальные фоны: V ±0.15, W ±0.20,
S ±0.15; масштаб 2.0.

Генератор `SeedSequence([seed, 6203])` создаёт три гладких поля
гауссовым фильтром с отражением на границе. Каждое центрируется
по среднему и делится на максимум абсолютного значения, поэтому
значения находятся в $[-1,1]$. Обозначим их $U_W$, $U_V$, $U_S$.

- Начальный фон влажности пропорционален $U_W$.
- Фон растительности пропорционален $`U_G=0.65U_W+0.35U_V`$.
- Фон качества почвы пропорционален $U_S$.
- Постоянные множители: $`R=1+a_P U_W`$, $`G=1+a_V U_G`$,
  $`Q=1+a_S U_S`$. По умолчанию $a_P=0.80$, $a_V=0.50$, $a_S=0.40$.

Сухие исходные участки получают меньше воды и в дальнейшем;
районы с менее благоприятным фоном растительности имеют меньшую
скорость роста. Исходные свойства почвы связаны со скоростью её
восстановления. Очаги задают дополнительное начальное повреждение,
а диффузия связывает соседние клетки. Новые случайные поля во время
расчёта не генерируются. В особо сильной засухе все участки могут со
временем деградировать — искусственного минимума растительности нет.

Это модельные предположения о местности, а не восстановленные по
измерениям карты. Seed воспроизводит поля при прежней сетке и размере
области; изменение разрешения меняет случайную реализацию.

## Движущиеся дождевые области

В v1.10.0 добавлен отдельный пространственный режим. По умолчанию
оставлено **неподвижное распределение**, поэтому прежние опыты
сохраняют свои результаты. Для включения выберите в поле «Карта
осадков» значение **«Движущиеся дождевые области»** и примените сброс.

Два компонента описывают разные свойства:

1. $R(x,y)$ — постоянное пространственное предпочтение климатического фона.
2. $H(x,y,t)$ — плавно переносимое погодное поле. Его движение меняет
   интенсивность местных осадков; оно не перемещает почву или растительность.

Для H используется гладкое поле F из 12 гармоник со случайными фазами
и волновыми векторами. Фазы и коэффициенты фиксируются независимым
потоком `SeedSequence([seed,104729])`. Поле вычисляется в координатах
$`(x-v_xt,y-v_yt)`$ со скоростями $`v_x=v\cos\theta`$ и
$`v_y=v\sin\theta`$. Погодный рисунок определён на неограниченной плоскости.

```math
H(x,y,t)=\exp\{3a\tanh F(x-v_xt,y-v_yt)\},
\qquad
P(x,y,t)=P(t)\frac{R(x,y)H(x,y,t)}{\operatorname{mean}(RH)}.
```

Поэтому $P(x,y,t)$ неотрицательно и в среднем по клеткам равно $P(t)$
в каждый момент. Сезонный и постоянный режимы по-прежнему управляют
общим количеством воды. Если $P(t)=0$, местные осадки тоже равны нулю.
При нулевом контрасте точно воспроизводится неподвижный режим.

| Параметр | Начальное значение | Смысл |
|---|---:|---|
| Контраст областей | 0.75 | Сила местных погодных различий, от 0 до 1 |
| Скорость | 0.50 | Координатные единицы за единицу t |
| Масштаб областей | 1.0 | Пространственная длина погодных различий |
| Направление | 30° | От оси +x против часовой стрелки: 0° вправо, 90° вверх |

Скорость 0 фиксирует погодный рисунок. Повторение с прежним seed даёт
ту же погоду; смена шага dt не создаёт новую последовательность дождя.
Влажность реагирует через уравнение воды с диффузией, испарением и
потреблением растительностью. Новый случайный шум на каждом шаге
не добавляется. Текущее поле и его границы сохраняются вместе с результатом.

Перенос полей осадков — стандартная составляющая краткосрочного
моделирования; пример описан в статье о
[pySTEPS](https://gmd.copernicus.org/articles/12/4185/2019/).
Здесь используется собственный демонстрационный генератор гармоник.
Его контраст, пространственный масштаб и скорость не калиброваны по
метеонаблюдениям; это сценарий поступления воды, не атмосферный прогноз.
